# 📚 Mathematics Problem Generator

A Python project for generating random mathematics exercises together with their solutions. The project was created to practice Python programming, random data generation and symbolic mathematics.

## Features
- Generates random quadratic equations with solutions (SymPy)
- Triangle area problems
- Geometric sequence exercises

## Technologies
- Python
- SymPy
- NumPy

## Purpose
This project was developed as a learning exercise to improve Python programming skills and explore automated generation and solving of mathematical problems.
